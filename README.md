## 🔒 API Key Security & Free Cloudflare Worker Proxy

Because this website will be publicly hosted on **GitHub Pages**, **the Google Gemini API key must never be committed to GitHub or exposed in frontend JavaScript.**

### Architecture:
```
[Visitor Browser (GitHub Pages)]
              │
              ▼ (POST without key)
[Free Cloudflare Worker Proxy]  <── Holds Encrypted GEMINI_API_KEY Secret
              │
              ▼ (Authenticated API Call)
[Google Gemini 3 API (AI Studio)]
```

### 📁 Security Guarantee:
- Your API key is saved **only** in `private/api_key.txt`.
- The `private/` folder is listed in `.gitignore` and is **never** committed to Git.
- A project-wide security scan confirms the key appears in **ZERO public files**.

## 🚀 Step-by-Step: Deploy Cloudflare Worker & Publish on GitHub Pages

### Phase 1: Deploy Free Cloudflare Worker (2 Minutes — No Coding Required)

1. **Sign Up / Log In to Cloudflare:**
   - Go to [https://dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up) (100% free, no credit card required).
2. **Create Worker:**
   - In the left sidebar, click **Workers & Pages**.
   - Click **Create application** -> **Create Worker**.
   - Name your worker (e.g. `coterotie-ai-proxy`) and click **Deploy**.
3. **Paste Worker Code:**
   - On your new worker's page, click **Edit code** (top right).
   - Replace all code in `worker.js` with the contents of [`cloudflare-worker/worker.js`](cloudflare-worker/worker.js).
   - Click **Deploy** (top right).
4. **Add Encrypted Secret:**
   - Return to the worker page (`<-` back arrow).
   - Go to **Settings** -> **Variables and Secrets** (or **Variables**).
   - Under **Secrets**, click **Add** (or **Add Secret**).
   - Variable name: `GEMINI_API_KEY`
   - Value: *(Paste your Google Gemini API key from `private/api_key.txt`)*
   - Click **Deploy** / **Save**.
5. **Copy Your Worker URL:**
   - Copy your public worker address, e.g.:
     `https://coterotie-ai-proxy.<your-subdomain>.workers.dev`
6. **Set Worker URL in Website:**
   - Open the website in your browser, click the 3D Chatbot button, tap the **⚙️ (Settings)** icon in the chat header, paste your Worker URL, and click **Save & Test**.
   - *(Optionally, you can also update `DEFAULT_WORKER_URL` on line 12 of `chat.js` before pushing).*

---

### Phase 2: Publish Your Website on GitHub Pages

1. **Initialize Git & Commit:**
   ```bash
   git init
   git add .
   git commit -m "feat: Côte Rôtie website with Gemini 3 AI Concierge and Cloudflare Worker proxy"
   ```
   *(Notice that `.gitignore` automatically blocks `private/`, protecting your API key!)*

2. **Push to GitHub:**
   ```bash
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```

3. **Enable GitHub Pages:**
   - In your GitHub repository, click **Settings**.
   - In the left sidebar, click **Pages**.
   - Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/ (root)`.
   - Click **Save**.
   - Within 1–2 minutes, your website will be live at `https://<your-username>.github.io/<your-repo-name>/`!

## 💻 Local Development Testing

Want to test the chatbot immediately on your local machine without waiting for Cloudflare?

1. **Run the included local proxy server:**
   ```bash
   python private/local_proxy.py
   ```
2. **Start the local website server in another terminal:**
   ```bash
   python -m http.server 8000
   ```
3. Open `http://localhost:8000`. The chat widget automatically detects `http://127.0.0.1:8787` and connects instantly!
